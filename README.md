Neon Bay is an original open-world crime game set in a sun-soaked coastal city. Play as courier Maya Reyes: explore on foot and by car, steal vehicles and weave through live traffic and pedestrians, draw police attention and evade a rising wanted level, and take on five story missions for Luz Ortega and Nico Vale — plus taxi fares, package runs and a dawn time trial — with a HUD that tracks health, cash, ammo, wanted stars, speed, the clock and your objective, and a live minimap of the whole city.

## Controls

- WASD or arrows: move / drive; Shift: run; Space: brake / handbrake
- Mouse: aim; click: fire pistol; F: punch; E: talk to a contact, enter or exit a car, start the time trial
- P or Esc: pause (S saves); R: back to title / retry after BUSTED or WASTED; Enter: new game; C: continue a saved game

## Run it

Run `node serve.ts`, then open http://localhost:8080.
